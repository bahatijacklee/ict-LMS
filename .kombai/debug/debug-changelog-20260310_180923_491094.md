## Root Cause Analysis

The landing page (`app/page.tsx`) uses external image URLs from multiple sources:
- Pexels for hero and feature images
- Pravatar for testimonial avatars

Next.js 16 requires explicit configuration of external image domains for security and performance optimization. Without this configuration, the Image component throws an error and blocks the page from rendering.

---

## Solution Applied

Added a `remotePatterns` configuration array that whitelists the following image sources:
1. **Pexels** (`images.pexels.com`) - Used in hero and 6 feature cards
2. **Picsum** (`picsum.photos`) - Alternative fallback for placeholders
3. **Unsplash** (`source.unsplash.com`) - Alternative stock photos
4. **Pravatar** (`i.pravatar.cc`) - Student testimonial avatars
5. **PlaceIMG** (`placeimg.com`) - Alternative placeholder service
