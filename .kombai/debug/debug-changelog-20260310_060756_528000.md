# Debug Changelog - Tailwind CSS Color Utility Errors

**Session ID**: 20260310_060756_528000  
**Date**: March 10, 2026  
**Issue**: Tailwind CSS failing to recognize custom color utilities (ring-brand, bg-brand-light, text-brand, etc.)

---

## Root Cause Analysis

The error `Cannot apply unknown utility class 'ring-brand'` occurred because:

1. **Tailwind v4 Syntax Limitation**: Custom colors defined in `tailwind.config.ts` were not being properly recognized when used with `@apply` directives in CSS that reference those custom colors
2. **PostCSS Processing**: The custom color tokens from `theme.extend.colors` were not accessible in the global CSS layer where they were being applied
3. **Runtime Resolution**: Tailwind's utility class generator couldn't resolve the arbitrary color reference at compile time

**Before:**
```css

  @apply outline-none ring-2 ring-brand ring-offset-2;
```

**Reason**: Removed `ring-brand` utility and replaced with CSS custom property that directly sets the ring color to the brand hex value (#0066CC)

## Prevention Notes

For future development:
1. Avoid using custom color names in `@apply` directives in global CSS
2. Use explicit hex values or CSS custom properties instead
3. Reserve `@apply` for Tailwind utilities (flex, grid, text-*, etc.)
4. Use direct CSS for custom color properties in class definitions
5. Consider using Tailwind's theme function in JS files instead of CSS
